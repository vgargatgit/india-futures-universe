# India Futures Universe

Independent producer for historical NSE individual-stock futures facts.

This repository owns FUTSTK contract-level data acquisition, parsing, quality
audits, release manifests, and pairs-lab compatibility outputs. Strategy
repositories consume pinned releases from this producer.

The first milestone is a bounded official-source discovery spike. It does not
build a trading strategy and does not claim executable futures readiness until
official contract-level data, dated lot sizes, identity mapping, and quality
gates pass.
